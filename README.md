# Bogotá Youth Information Centre (English version)

English version of the youth indicators dashboard I built for the Youth Subdirectorate of Bogotá’s District Secretariat of Social Integration (SDIS). It covers the seven dimensions of the District Youth Policy, from population and education to employment, health, culture, safety and habitat, using official sources.

Live page: https://carolinahernandez2019.github.io/bogota-youth-indicators/

The official dashboard, in Spanish, is at https://sdis-juventud.github.io/tablero-cij/ and its code at https://github.com/SDIS-Juventud/tablero-cij. This copy keeps the data as published in November 2026 and is not updated.

It is a static site (HTML, JavaScript, Chart.js and Leaflet). To view it locally, run `python -m http.server` in this folder and open http://localhost:8000.
